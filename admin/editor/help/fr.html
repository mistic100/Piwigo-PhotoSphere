Cette page vous permet de configurer l'affichage de votre Photo Sphere et de créer des « visites virtuelles » en reliant plusieurs Photo Spheres à l'aide de repères cliquables.

Onglet Paramètres

Cet onglet vous permet de configurer l'apparence générale de votre panorama. La section « Correction de l'orientation » permet notamment de corriger l'orientation de votre appareil photo après la prise de vue. Utilisez ces paramètres pour orienter tous vos panoramas de la même façon (par exemple, avec l'avant tourné vers le nord), afin que les liens entre les panoramas soient cohérents.

Remarque : la bibliothèque Photo Sphere Viewer prend en charge les métadonnées XMP intégrées, ajoutées par la plupart des appareils photo 360°. Vous pouvez donc choisir de modifier vous-même les données XMP avant l'envoi (paramètre GPano:Pose).

Pour définir l'orientation par défaut au chargement d'une Photo Sphere, utilisez l'onglet « Centre d'intérêt ».

Photos liées

C'est ici que vous pouvez relier plusieurs panoramas. Cliquez d'abord sur le bouton « Ajouter un lien » pour sélectionner une Photo Sphere disponible (seules les images des mêmes albums que l'image actuelle sont disponibles), puis cliquez sur le panorama pour placer le repère.
Vous pourrez également créer un lien de retour depuis le panorama cible. Si vous choisissez cette option, le repère sera placé à une position symétrique, que vous pourrez modifier par la suite.

Après avoir ajouté des liens, vous pouvez déplacer un repère en cliquant sur le bouton , puis sur le nouvel emplacement dans le panorama.

L'icône indique qu'un lien de retour existe depuis le panorama cible.

Cliquez sur l'icône pour ouvrir la page de modification du panorama correspondant.

Enfin, utilisez le bouton pour afficher tous les panoramas reliés entre eux. Dans cette vue, cliquez sur l'icône d'une flèche pour supprimer le lien (dans les deux sens), ou sur une vignette pour ouvrir la page de modification correspondante.

Dans la page principale de configuration du plugin, vous pouvez modifier l'apparence des liens et leur taille.
