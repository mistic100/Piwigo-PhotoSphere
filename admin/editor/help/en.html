Configure how your Photo Sphere is displayed and create "virtual tours" by linking Photo Spheres with clickable markers.

Settings tab

Configure your panorama's overall appearance on this tab. Use "Orientation correction" to adjust the camera's orientation after taking the photo. Keep all panoramas oriented consistently (for example, facing north) so links between them appear in the right direction.

Note: Photo Sphere Viewer supports embedded XMP metadata, which most 360° cameras add automatically. You can also edit the XMP data yourself before uploading, using the GPano:Pose parameters.

Set a Photo Sphere's default orientation in the "Center of interest" tab.

Linked photos

Link panoramas here. Click "Add a new link" and select a Photo Sphere (only images in the same albums as the current image are available), then click the panorama to place the marker.
You can also create a return link from the target panorama. It will be placed symmetrically, but you can adjust its position later.

To move a marker, click the button, then click its new position on the panorama.

The icon indicates that a return link exists from the target panorama.

Click the icon to edit the corresponding panorama.

Click the button to view all linked panoramas. Click the on an arrow to remove the link in both directions, or click a thumbnail to edit that panorama.

On the main plugin configuration page, you can change how links look and set their size.
